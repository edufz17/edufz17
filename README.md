### 📊 Featured Project

**[REE Energy Prices ETL](https://github.com/edufz17/PipelineETL)**  
*Personal Data Engineering Project*

A modular ETL pipeline built with **Python, Pandas, PostgreSQL, and Docker Compose** to process electricity market data from the Spanish electricity system.

- **Extract:** Retrieve electricity market data from Red Eléctrica's public REST API.
- **Transform:** Clean and validate records, handle missing values, and normalize timestamps to UTC.
- **Load:** Store processed data in PostgreSQL using idempotent operations to prevent duplicate records.
- **Environment:** Organize the pipeline into independent modules and manage the database environment with Docker Compose.

The core ETL pipeline is functional and is being expanded with additional features.
