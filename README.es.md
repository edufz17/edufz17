### 📊 Proyecto destacado

**[REE Energy Prices ETL](https://github.com/edufz17/PipelineETL)**  
*Proyecto personal de ingeniería de datos*

Pipeline ETL modular desarrollado con **Python, Pandas, PostgreSQL y Docker Compose** para procesar información del mercado eléctrico español.

- **Extracción:** Obtención de datos del mercado eléctrico mediante la API REST pública de Red Eléctrica.
- **Transformación:** Limpieza y validación de registros, tratamiento de valores nulos y normalización de fechas a UTC.
- **Carga:** Almacenamiento de los datos procesados en PostgreSQL mediante operaciones idempotentes para evitar duplicados.
- **Entorno:** Organización del pipeline en módulos independientes y gestión del entorno de base de datos mediante Docker Compose.

El núcleo ETL está operativo y actualmente estoy ampliando el proyecto con nuevas funcionalidades.
